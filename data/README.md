# Insider/IQ Dataset (CERT r4.2)

This directory contains the CERT r4.2 Insider Threat Dataset, which is synthetic data generated by Carnegie Mellon University (CMU) for prototyping and training machine learning models for insider threat detection. 

> **Important**: This is strictly synthetic test data and does NOT contain actual employee information or real network logs.

## Field Mapping for Future Milestones

For the backend/ML milestones, the CERT log files correspond to the frontend Activity Types as follows:

| CERT CSV File | Application Activity Type |
| ------------- | ------------------------- |
| `logon.csv`   | **Login Events** |
| `device.csv`  | **USB/Device** (Data Transfer) |
| `http.csv`    | **HTTP/Browsing** |
| `email.csv`   | **Email Activities** |
| `file.csv`    | **File Downloads/Uploads** |

This dataset should NOT be parsed or loaded by the frontend. It is reserved for the backend processing engine.
