# Week 6 Documentation

## UEBA Intelligence & Risk Analytics

### 1. Objective

The objective of Week 6 is to provide User and Entity Behavior Analytics (UEBA), risk analytics, and security analyst prioritization capabilities.

The dashboard was enhanced to help security analysts understand abnormal employee behavior and prioritize users for investigation.

---

### 2. UEBA Behavioral Analytics

The system provides a behavioral profile for each anomalous user.

The following activities are analyzed:

* Login activity
* USB activity
* File activity
* Email activity
* Web activity

The Streamlit dashboard presents these activities visually using interactive charts.

This allows analysts to quickly identify unusually high levels of activity across different behavioral categories.

---

### 3. Behavioral Investigation

The investigation module allows an analyst to select an anomalous employee.

For the selected user, the system displays:

* Risk score
* Risk level
* Anomaly score
* Behavioral activity counts
* Behavioral investigation explanation
* UEBA activity visualization

This provides a consolidated view of the employee's suspicious behavior.

---

### 4. Risk Analytics

A risk score distribution chart was added to the dashboard.

This visualization helps analysts understand how risk scores are distributed among anomalous users.

A risk-level summary was also implemented to display the distribution of:

* High-risk users
* Medium-risk users
* Low-risk users, if present

Current results:

* **17 High-risk users**
* **33 Medium-risk users**
* **50 anomalous users**

---

### 5. Security Analyst Priority View

A Security Analyst Priority View was added to the dashboard.

Users are sorted by their risk score in descending order.

The priority table displays:

* User ID
* Risk score
* Risk level
* Anomaly score
* Behavioral explanation

This allows analysts to focus on the highest-risk users first.

---

### 7. Dashboard Technologies

The Week 6 analytics dashboard uses:

* Streamlit for the user interface
* Pandas for data processing
* Plotly for interactive visualization
* Python for analytics
* CSV-based risk reports generated by the ML pipeline

---

### 8. Week 6 Outcome

UEBA intelligence, behavioral investigation, risk analytics, and analyst prioritization were successfully integrated into the existing security dashboard.

The system now provides an end-to-end workflow:

**Behavioral Data → Anomaly Detection → Risk Scoring → UEBA Analysis → Threat Investigation → Analyst Prioritization**

The enhanced dashboard provides security analysts with actionable behavioral intelligence for further investigation.
